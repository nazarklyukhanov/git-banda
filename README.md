# ITMO Padel 🎾

Тестовый репозиторий — сайт студенческого падел-клуба университета ИТМО.

## Что внутри

- `index.html` — одностраничный сайт клуба: о клубе, расписание тренировок, цены, контакты. Без зависимостей и сборки — чистые HTML/CSS.

## Как посмотреть

Просто открой `index.html` в браузере:

```bash
open index.html
```

## Ветки

- `main` — стабильная версия
- `develop` — ветка разработки
